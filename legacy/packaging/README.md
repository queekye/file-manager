# Historical packaging references

These are the original packaging scripts from private fileManager commit
530c2ca9baa0e90993c6c3af89b9e1766a4a5281. They are retained for design/history,
not an approved installer workflow. Do not run them for the public release:
they assume old resource paths, installed-directory writable state and registry
changes. The maintained build entry is ../../scripts/build_windows.py.
The public source does not register menus, auto-start or hotkeys during tests.
